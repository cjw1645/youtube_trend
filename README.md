# 유튜브 트렌드 AI 대시보드

인기 영상과 검색 결과를 살펴보고, 영상의 공개 정보를 바탕으로 콘텐츠 아이디어를 얻는 서비스입니다. 유튜브 채널 편집자가 트렌드를 탐색하고 다음 영상의 방향을 잡을 수 있도록 돕습니다.

[서비스 이용하기](https://youtube-trend-orpin.vercel.app)

## 영상 탐색

왼쪽 메뉴(모바일은 메뉴 버튼)에서 홈·AI 대화·관심 영상으로 이동합니다. 홈의 ‘지금 트렌드’ 화면은 카테고리 제한 없는 YouTube API 인기 목록으로 시작하며 전체 YouTube의 인기 순위를 보장하지 않습니다. 어두운 중립 배경과 빨강 강조색을 사용합니다.

검색어를 입력하고 Enter 또는 검색 버튼으로 조회하세요. 카테고리·정렬 변경은 적용 버튼으로 실행하고, 초기화하면 기본 인기 목록으로 돌아갑니다. 카테고리 선택은 검색 조회를 사용합니다. 검색 결과는 한국에서 시청 가능한 영상이며 한국 채널·한국어 영상만을 보장하지 않습니다. 기본 인기 목록의 조회수순/최신순은 받은 목록 안에서 정렬합니다.

목록은 썸네일·제목·채널명·조회수·업로드일·카테고리를 표시합니다. 정렬은 인기순·조회수순·최신순입니다. 기본 인기순은 API 제공 순서를 그대로 유지합니다. 카테고리/키워드 검색의 API 기본 순서는 관련도순이며 조회수 순위나 전체 YouTube 인기 순위를 뜻하지 않습니다. 카테고리/키워드 검색은 `search.list`로 후보를 조회하고 `videos.list`로 통계를 일괄 보완합니다. 기본 인기 목록은 `videos.list(chart=mostPopular, regionCode=KR)`를 사용합니다.

영상 카드를 누르면 설명, 태그, 조회수, 좋아요, 댓글 수와 채널 구독자 수가 표시됩니다. 공개되지 않은 정보는 ‘정보 없음’으로 표시하고 0과 구분합니다. 통계는 조회 시점에 따라 달라질 수 있으며 정렬은 조회한 영상 범위에 적용됩니다.

## 관심 영상

관심 있는 영상의 저장 버튼을 누르세요. 관심 영상 메뉴에서 모아 볼 수 있고 저장 버튼을 다시 누르면 해제됩니다. 저장 목록은 같은 브라우저에서 새로고침해도 유지됩니다.

## AI 분석

1. 홈·관심 목록의 ‘이 목록으로 AI 질문’ 또는 상세의 ‘이 영상으로 AI 질문’을 누릅니다. 원하는 영상만 사용하려면 ‘분석 영상 직접 선택’에서 1~20개를 선택하세요.
2. AI 대화 화면에서 출처·대상 목록을 확인하고 질문을 입력합니다. 예시 질문은 입력란만 채웁니다. 현재 검색/홈 결과와 관심 영상 대상을 명시적으로 전환할 수 있습니다.
3. 분석 대상과 개수를 확인하고 전송 버튼 또는 Enter를 누릅니다. Shift+Enter로 줄바꿈할 수 있습니다.
4. 질문에 맞춘 답변을 확인합니다. 제목 나열, 영상 비교, 트렌드 분석이나 원하는 개수의 콘텐츠 아이디어를 요청할 수 있습니다.

예시 질문:

- 현재 유튜브 트렌드를 분석해줘
- 이 영상이 인기 있는 이유를 분석해줘
- 다음 콘텐츠 아이디어 3개를 제안해줘

기본은 적용 정렬의 화면 앞쪽 최대 20개, 직접 선택은 화면 안에서 선택한 1~20개, 상세는 1개입니다. 선택한 영상은 클릭한 순서 대신 화면 순서로 전달합니다. 새 조회·정렬·관심 목록 변경·새로고침은 선택 표시를 초기화하고 메뉴 이동은 유지합니다. 이미 전달한 AI 대상과 진행 중 요청은 새 검색이나 관심 해제로 바뀌지 않습니다. 순위는 해당 대상 안에서만 비교합니다.

같은 탭 새로고침 후 마지막 대상·질문 초안·완료 대화를 복원합니다. 초안은 2,000자, 완료 대화는 최근 10건·답변당 32,000자·총 512KiB·최종 수정 후 최대 24시간입니다. 저장 공간 제한 때문에 일부 기록은 복원되지 않을 수 있습니다. 진행 중 요청은 결과 수신 중단 안내만 표시하고 자동 재전송하지 않습니다. 서버가 기존 요청을 계속 처리할 수 있으므로 다시 전송하면 새 호출이 발생합니다. 대상 기록과 대화 기록은 각각 지울 수 있습니다. 탭을 닫아도 브라우저의 세션 복원 설정에 따라 기록이 남을 수 있습니다.

완료 답변의 ‘답변 복사’ 또는 ‘텍스트 내보내기’로 질문·답변·당시 근거 영상·출처·완료 시각을 함께 보관할 수 있습니다. 복사 권한이 없으면 텍스트 내보내기를 사용하세요.

질문 전송 때 서버가 대상 ID의 최신 제목·설명·태그·공개 통계를 다시 조회합니다. 저장 통계를 사실 근거로 사용하지 않으며 대화 이력을 모델에 보내지 않습니다. 영상이나 음성을 직접 분석하지 않으며, 정보가 부족하면 판단의 한계를 안내합니다. 콘텐츠 제안은 기획 아이디어이므로 실제 제작에 앞서 직접 검토하세요.

트렌드 분석을 요청하면 `[핵심 요약]` 특징 2–3줄, `[근거 데이터]` 대상 내 조회수 상위 3개의 영상명·조회수·업로드일, `[콘텐츠 제안]` 제목·소재·썸네일·구성 방향·참고 근거를 포함한 기획 제안 3개를 제공합니다. 영상이 부족하면 있는 근거만 사용합니다. 판단 근거는 영상의 공개 정보와 해석의 연결, 확인할 수 없는 한계를 문장으로 설명합니다. 요약과 근거, 제안의 설명은 키워드 나열 대신 완결된 문장으로 제공합니다. 다른 질문은 요청한 형식에 맞춰 답하고 필요한 근거를 함께 제시합니다. 공개 정보만으로 인기 원인이나 시청자 반응, 실시간 순위 변동을 확정하지 않습니다.

## 이용 중 오류가 발생하면

영상 조회 오류는 재시도 버튼으로 다시 요청할 수 있습니다. AI 분석 오류는 안내를 확인한 뒤 전송 버튼으로 다시 질문하세요. 사용 한도 초과 안내가 나오면 시간이 지난 뒤 이용해 주세요.

로딩·검색 결과 없음·관심 영상 없음·일반 오류·할당량 초과를 구분합니다. 삭제되거나 비공개인 영상은 상세를 표시할 수 없습니다. AI는 조회 불가 대상을 제외하고 안내하며 유효 대상이 없으면 모델을 호출하지 않습니다. 처리 중 중복 전송과 자동 반복 재시도를 하지 않습니다.

## 개발 환경과 로컬 실행

React + TypeScript, Vite, Tailwind CSS를 사용하며 `/api` 서버 코드는 Vercel Functions에서 실행합니다. 개발 도구가 요구하는 Node.js 버전과 npm을 설치한 뒤 다음 명령을 실행합니다.

```sh
npm install
npm run dev
```

루트의 `.env.example`에는 `YOUTUBE_API_KEY`, `GEMINI_API_KEY` 이름과 공란 값만 있습니다. 개발자가 직접 루트 `.env.local`을 만들고 발급한 값을 설정하세요. 개발 서버의 기존 서버 로더가 이 파일을 읽습니다. 실제 환경 파일은 Git에 추가하지 않습니다. 로컬 `/api` 연결은 Vite 개발 전용 플러그인이 처리하며 Vercel Functions 통합 확인은 설치된 Vercel CLI의 `vercel dev`로 진행할 수 있습니다. `npm run build`는 타입 검사와 Production 번들을 생성합니다. `npm run preview`는 정적 번들 확인용이며 API 서버를 대신하지 않습니다.

## API Key 발급과 설정

1. [YouTube Data API 시작 안내](https://developers.google.com/youtube/v3/getting-started)에 따라 Google Cloud 프로젝트에서 YouTube Data API v3를 활성화하고 API Key를 발급합니다. 공개 영상 조회에 이 키를 사용합니다.
2. [Gemini API Key 안내](https://ai.google.dev/gemini-api/docs/api-key)에 따라 Google AI Studio에서 프로젝트의 API Key를 발급합니다. 현재 서버는 Flash 계열 모델을 사용합니다.
3. 로컬에서는 위 서버 환경변수로, 배포에서는 Vercel 프로젝트 환경변수로 설정합니다. 키는 `api/` 서버 코드에서만 `process.env`로 읽습니다. 브라우저는 `/api/*`만 호출하며 키에 `VITE_` 접두사를 사용하지 않습니다. 키를 코드·응답·오류·로그에 넣지 않습니다.

YouTube와 Gemini의 할당량 및 무료 이용 가능 범위는 프로젝트·모델·정책에 따라 달라집니다. 실제 평가 전에 호출 예산을 정하고 429 응답이면 중단하세요. 실제 Key를 바꾸거나 공개 오류 주입 기능으로 오류 화면을 만들지 않습니다.

## Vercel 배포

1. [GitHub 저장소](https://github.com/cjw1645/youtube_trend)를 Vercel 프로젝트에 연결하고 Vite 빌드 명령 `npm run build`, 출력 디렉터리 `dist`를 확인합니다. 이 서비스는 Vercel Hobby를 배포 대상으로 사용합니다.
2. [환경변수 설정](https://vercel.com/docs/environment-variables)에서 `YOUTUBE_API_KEY`, `GEMINI_API_KEY`를 사용할 Production/Preview 환경에 등록합니다. 변경한 설정은 새 배포에 적용합니다.
3. [Git 배포 안내](https://vercel.com/docs/git)에 따라 Production Branch를 `main`으로 설정합니다. 이 저장소의 main push는 Production 자동 배포를 실행하므로 Preview 검증 후 진행합니다.
4. 배포 URL에서 영상 조회·검색·필터·정렬·상세·관심 영상·AI 답변과 오류 안내를 확인합니다. 브라우저 번들과 네트워크 요청에 키가 노출되지 않는지도 확인합니다.

공유 자료는 저장소 링크, 배포 URL, 공란 값의 `.env.example`, 이 README, 영상 조회·AI 답변·오류 화면 캡처입니다. 로컬 문서·평가 자료·PDF·검수 스크립트의 기존 Git 제외 정책을 유지합니다. 새로 구현한 변경은 배포 전까지 위 서비스 URL에 반영되지 않습니다.

## 요구사항 범위

원문 요구사항의 공개 영상 목록·검색/필터/정렬·상세·관심 영상·메타데이터 기반 Gemini 분석을 제공합니다. 이후 합의에 따라 단일 카테고리 드롭다운, React 사이드바, 별도 AI 화면, 최대 20개 대상 선택과 같은 탭 대화 복원을 적용했습니다. 레퍼런스 사이트는 흐름과 정보 배치만 참고하며 브랜드·문구·자산·디자인을 복제하지 않습니다. 자체 트렌드 키워드 수집, Shorts 확정 분류, 광고·수익 추정·채널 비교·캠페인 관리, 영상/음성 다운로드·분석은 제공하지 않습니다.
