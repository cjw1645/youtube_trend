# 유튜브 트렌드 AI 대시보드

인기 영상과 검색 결과를 살펴보고, 영상의 공개 정보를 바탕으로 콘텐츠 아이디어를 얻는 서비스입니다. 유튜브 채널 편집자가 트렌드를 탐색하고 다음 영상의 방향을 잡을 수 있도록 돕습니다.

[서비스 이용하기](https://youtube-trend-orpin.vercel.app)

## 영상 탐색

첫 화면에서 한국 인기 영상을 확인할 수 있습니다. 검색어를 입력하고 Enter 또는 검색 버튼을 누르면 관련 영상을 찾습니다. 카테고리로 범위를 좁히고 조회수순이나 최신순으로 정렬할 수 있습니다.

영상 카드를 누르면 설명, 태그, 조회수, 좋아요, 댓글 수와 채널 구독자 수가 표시됩니다. 공개되지 않은 정보는 별도로 안내합니다. 통계는 조회 시점에 따라 달라질 수 있으며 정렬은 조회한 영상 범위에 적용됩니다.

## 관심 영상

관심 있는 영상의 저장 버튼을 누르세요. 상단의 관심 영상 화면에서 모아 볼 수 있고 저장 버튼을 다시 누르면 해제됩니다. 저장 목록은 같은 브라우저에서 새로고침해도 유지됩니다.

## AI 분석

1. 분석할 목록을 열거나 영상 상세를 선택합니다.
2. AI 분석 패널을 펼쳐 질문을 입력합니다. 예시 질문을 누르면 입력란이 채워집니다.
3. 분석 대상과 개수를 확인하고 전송 버튼을 누릅니다.
4. 핵심 요약, 근거 데이터, 콘텐츠 제안을 확인합니다.

예시 질문:

- 현재 유튜브 트렌드를 분석해줘
- 이 영상이 인기 있는 이유를 분석해줘
- 다음 콘텐츠 아이디어 3개를 제안해줘

목록과 관심 목록은 화면 순서대로 최대 20개, 상세 화면은 선택한 영상 1개를 분석합니다. 답변에 표시되는 상위 영상은 분석 대상 안에서의 조회수 순서입니다. 화면을 이동해도 답변 당시의 분석 대상을 확인할 수 있습니다.

AI는 영상의 제목·설명·태그·공개 통계를 근거로 답합니다. 영상이나 음성을 직접 분석하지 않으며, 정보가 부족하면 판단의 한계를 안내합니다. 콘텐츠 제안은 기획 아이디어이므로 실제 제작에 앞서 직접 검토하세요.

## 이용 중 오류가 발생하면

영상 조회 오류는 재시도 버튼으로 다시 요청할 수 있습니다. AI 분석 오류는 안내를 확인한 뒤 전송 버튼으로 다시 질문하세요. 사용 한도 초과 안내가 나오면 시간이 지난 뒤 이용해 주세요.
